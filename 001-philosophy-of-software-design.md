## Chapter 1
> Last updated: 11/17/2026

Make code simpler and more obvious. Encapsulate complexity so that you can work on your task without understanding the whole system. 
The waterfall model (requirements → design → code → testing → maintenance) doesn’t work for software systems.

Agile development is the standard today because problems are detected quickly: a feature goes through a short cycle and is evaluated at the end.

Incremental development treats software design as a continuous activity. It never ends, and with every new feature, developers should ask themselves about design. The goal of the book is to explain what complexity is, how to remove unnecessary complexity, and which 
techniques help minimize it during development.

Red flags: warning signs that a piece of code is probably more complicated than it needs to be.
